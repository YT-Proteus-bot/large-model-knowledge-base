# 大模型面试知识库

面向大模型算法 / AI Agent / 后端岗位的中文面试题库，覆盖大模型从底座原理到工程落地的完整链路：Transformer、LLM 基础、微调（SFT / LoRA / RLHF / 蒸馏）、RAG、Agent、推理与显存优化、分布式训练、评测、多模态，以及手撕代码与面经。

既可以直接当笔记读，也可以作为 RAG / 检索增强的语料库——每个主题一篇文章、文档内每题统一标题，很多题目带标准答法与追问方向。

## 目录结构

仓库分成两层，同一份内容有两种形态：

- **原始层**（仓库根目录的各个主题文件夹 + `*.pdf`）：从飞书知识库导出的原始 Markdown 与配套 PDF 原件，保留原排版与图示，适合直接阅读。
- **清洗层** `knowledge-base/`：为检索重新生成的知识库。一文一文件，文件头部带 YAML 元数据（主题 / 子主题 / 来源链接 / 字数 / 题数），每道题统一为 `## 题N：…` 标题，附带 `_meta/catalog.csv` 全量目录与重复 / 解析失败的排查记录。

## 怎么用

**直接阅读**：从 [knowledge-base/README.md](knowledge-base/README.md) 的总索引进入，或打开任意主题的 `_index.md`。用 Obsidian / VS Code 打开仓库可以获得最好的 Markdown 阅读与双链体验。

**全文检索**：

```bash
# 按关键词找题
rg -n "KV Cache" -g "*.md"

# 只看某主题下所有题目标题
rg -n "^## 题" knowledge-base/RAG核心面（精选）
```

**作为 RAG 语料**：`knowledge-base/` 已按「一文一文件 + 题级标题 + YAML 元数据」组织好，可直接切片入库；`_meta/catalog.csv` 提供文档级索引。
