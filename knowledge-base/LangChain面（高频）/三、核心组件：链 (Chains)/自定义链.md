# 自定义链

> 主题：LangChain面（高频） › 三、核心组件：链 (Chains)　｜　原始文件：LangChain面（高频）/三、核心组件：链 (Chains)/自定义链.md

## 题1：如果要自定义一条链，需要继承什么类？必须实现哪些方法？

最正统的做法是继承 Chain 基类（from langchain.chains.base import Chain）。早期版本里大家也会直接继承 LLMChain 或者 SimpleSequentialChain 去魔改，但现在有 Runnable 协议之后，我更建议在思想上先理解：链的本质就是一个可运行对象，有输入、有输出、有内部逻辑，并且能被组合。

但直接回答你的问题：继承 Chain 时，必须实现的硬性方法其实只有两个：

- _call：同步执行的核心逻辑，接收 dict 输入，返回 dict 输出。
- @property 的 input_keys 和 output_keys：告诉框架你这条链吃哪些键、吐哪些键。

为什么说“只有两个”？因为很多人会提到必须实现 _acall，但从技术上讲，如果你不实现它，调用 ainvoke 时会自动用 run_in_executor 把同步的 _call 包成异步，虽然不推荐，但不会报错。不过，真要上生产，你必须把 _acall 老老实实写好，这个后面再细说。

还有一个经常被忽略但非常重要的点：如果你想用 chain.invoke 这种统一接口，你需要知道在 LangChain 0.1.x 之后，自定义 Chain 最好同时混入 Runnable 的特性。更现代的做法是直接实现 Runnable 协议，而不是死守旧 Chain 类。不过面试场景中，面试官通常还是问旧 Chain 那一套，所以我会这样回答：“可以继承 Chain，必须实现 _call 方法和 input_keys/output_keys 属性。如果你还需要更灵活的流式、事件回调等控制，建议了解 RunnableLambda 或者直接实现 Runnable 协议，那里你只需要实现 invoke 和可选的 ainvoke 等。”

我个人习惯在自定义链时还会重写 _chain_type 属性返回一个自定义字符串，这在监控和日志里非常有用，一眼就知道是哪个链出了问题。

## 题2：写一个自定义链，输入是一段文本，输出是这段文本的英文翻译和情感分析结果。

我先给个具体实现，然后再说设计上的取舍。假设我们底层有两个能力：翻译用某个 LLM，情感分析用另一个轻量模型或同一个 LLM 的不同 prompt。代码可以这样写：

```
from typing import Dict, Any, List
from langchain.chains.base import Chain
from langchain_core.language_models import BaseLLM
from langchain_core.prompts import PromptTemplate
class TranslateAndSentimentChain(Chain):
    """输入一段文本，输出英文翻译和情感分析结果"""
    llm: BaseLLM
    translate_prompt: PromptTemplate = PromptTemplate(
        input_variables=["text"],
        template="将以下文本翻译成英文，只返回英文译文：\n{text}"
    )
    sentiment_prompt: PromptTemplate = PromptTemplate(
        input_variables=["english_text"],
        template="分析下面英文文本的情感，只输出一个单词（positive/negative/neutral）：\n{english_text}"
    )
    @property
    def input_keys(self) -> List[str]:
        return ["text"]
    @property
    def output_keys(self) -> List[str]:
        return ["english_translation", "sentiment"]
    def _call(self, inputs: Dict[str, Any]) -> Dict[str, Any]:
        text = inputs["text"]
        # 第1步：翻译
        translate_input = self.translate_prompt.format(text=text)
        translation = self.llm.invoke(translate_input).strip()
        # 第2步：情感分析
        sentiment_input = self.sentiment_prompt.format(english_text=translation)
        sentiment = self.llm.invoke(sentiment_input).strip().lower()
        return {
            "english_translation": translation,
            "sentiment": sentiment
        }
```
