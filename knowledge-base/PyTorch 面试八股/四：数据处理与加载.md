# 四：数据处理与加载

> 主题：PyTorch 面试八股　｜　原始文件：PyTorch 面试八股/四：数据处理与加载.md

## 题1：自定义Dataset需要实现哪两个基本方法？

在 PyTorch 中，自定义数据集必须继承 torch.utils.data.Dataset 并实现两个核心方法：

- len(self)：返回数据集的样本总数。这是 DataLoader 计算批次数量、控制迭代次数的依据。
- getitem(self, idx)：根据给定的索引 idx，返回单个样本（及其标签或附加信息）。这是数据加载的核心，所有数据预处理、增强操作通常都在此方法内完成。

```
from torch.utils.data import Dataset
class MyDataset(Dataset):
    def __init__(self, data, targets):
        self.data = data
        self.targets = targets
    def __len__(self):
        return len(self.data)
    def __getitem__(self, idx):
        sample = self.data[idx]
        label = self.targets[idx]
        # 可在此进行任何预处理、增强
        return sample, label
```

深入理解：

- len 必须返回一个非负整数，否则 DataLoader 无法正确采样。如果数据集是流式的或长度不确定，可以继承 IterableDataset 并改为实现 iter。
- getitem 返回的数据格式是自由的，但通常由 collate_fn 统一打包为 batch。对于监督学习，返回 (input, target) 是最常见的约定。

## 题2：getitem 通常返回什么格式的数据？

getitem 返回的格式完全取决于任务和 collate_fn 的约定，但最常见的规范是返回一个元组 (input, target) 或字典。

常见格式：

1. 监督学习（图像分类）：返回 (image_tensor, label)，其中 image_tensor 是 (C, H, W) 的张量，label 是整数标量。
1. 自然语言处理（文本分类）：返回 (text, label) 或预先 tokenize 的 (input_ids, attention_mask, label)。
1. 多任务/复杂场景：返回字典 {'image': img, 'mask': mask, 'label': label}，这时必须配合自定义 collate_fn 来正确堆叠字典中的每个字段。
1. 生成式任务：对于指令微调，常返回 (prompt, response) 或已经编码的 input_ids 和 labels。

关键：getitem 返回的张量不需要具有相同大小，collate_fn 负责在 batch 维度进行填充或拼接。

```
def __getitem__(self, idx):
    img = self.load_image(idx)          # (3, 224, 224)
    label = self.labels[idx]
    return img, label
```

## 题3：如何将图像和标签组成一个样本返回？

最直接的方式是在 getitem 中读取图像并转换成张量，然后与标签一起打包成元组返回。

```
from PIL import Image
import torch
class ImageDataset(Dataset):
    def __init__(self, image_paths, labels, transform=None):
        self.image_paths = image_paths
        self.labels = labels
        self.transform = transform
    def __len__(self):
        return len(self.image_paths)
    def __getitem__(self, idx):
        img = Image.open(self.image_paths[idx]).convert('RGB')
        if self.transform:
            img = self.transform(img)   # 返回 Tensor (C, H, W)
        label = self.labels[idx]
        return img, label               # 元组形式
```
