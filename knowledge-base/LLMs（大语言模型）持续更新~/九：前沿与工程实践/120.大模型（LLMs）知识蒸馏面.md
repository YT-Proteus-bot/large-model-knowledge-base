## 题1：什么是知识蒸馏？在 LLM 中的典型应用场景有哪些？

> ✍️ **知识蒸馏由 Hinton** 等人在 2015 年正式提出。其核心思想是：让学生模型不仅学习训练数据中的“硬标签”（ground truth），更要去拟合教师模型在输出层产生的“软标签”（soft labels）——即教师对每个类别的概率分布。这个概率分布中蕴含了教师从数据中学到的“暗知识”（dark knowledge），例如类别之间的相似性、非标签类别的相对概率等。软标签相比硬标签包含更丰富的信息，能够指导学生用更少的参数达到接近教师的泛化能力。

**在 LLM 中，知识蒸馏的典型应用场景包括：**

1. **通用模型压缩**：将数百亿、数千亿参数的庞然大物（如 GPT-4、PaLM）的能力蒸馏到几亿到几十亿参数的小模型上，以便在端侧或低资源环境中部署。例如，**用 GPT-4 的输出来微调一个 7B 的学生模型。**
1. **任务特化蒸馏：**将通用大模型在特定任务上的表现蒸馏到一个小模型上。比如，将 LLM 的数学推理、代码生成、翻译等能力通过收集特定任务的教师输出，训练出专精于该任务的小模型。
1. **指令跟随与对齐蒸馏：**将大模型经过 RLHF 后的对齐行为（如安全性、有用性、风格）传递给小模型。典型做法是用教师模型生成大量的指令-回复对，然后用这些数据监督微调学生模型（即 SFT 蒸馏），有时还会进一步用教师的评分作为奖励信号进行 RL 蒸馏。
1. **多模态和跨语言蒸馏：**将大型多模态模型或跨语言模型的能力蒸馏到单一模态或特定语言的模型中，降低多模态推理成本。
1. **渐进式蒸馏与自蒸馏：**采用多次迭代，将大模型的知识逐步蒸馏到更小的模型，或者让模型以自身的历史版本作为教师进行蒸馏，以提升数据效率和泛化性。。

## 题2：白盒蒸馏和黑盒蒸馏的区别是什么？各举一个例子。

> 〔图片：原文此处为图片或公式截图，未随文档导出〕

白盒蒸馏指学生模型可以完全访问教师模型的内部结构和参数，从而利用教师的中间表示（如隐藏层状态、注意力矩阵、嵌入等）作为额外的监督信号，而不仅仅是最终输出。学生模型的中间层被训练去模仿教师模型对应层的特征，这种通常称为“特征蒸馏”或“中间层蒸馏”。

- 例子：TinyBERT。它从 BERT-base 蒸馏时，不仅学习教师最后一层的 logits，还学习教师嵌入层的输出、各 Transformer 层的隐藏状态以及自注意力矩阵。通过缩小对应层之间的 MSE 损失，TinyBERT 获得了超越单纯 logits 蒸馏的效果。

黑盒蒸馏则只能通过查询教师模型的输入-输出接口来获取知识，无法访问内部参数或中间表示。教师模型就像被封装在 API 后面的“黑盒”。这是目前 LLM 蒸馏的最主要形式，因为最强大的商业模型（如 GPT-4、Claude）只能通过 API 访问。

- 例子：用 GPT-4 API 生成大量的高质量对话或推理数据，然后使用这些数据直接通过监督微调（SFT）训练一个较小的开源模型（如 LLaMA-7B）。这就是典型的黑盒蒸馏，因为学生只看到了教师生成的最终文本。
