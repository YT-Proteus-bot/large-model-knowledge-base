# 82.大模型（LLMs）ReAct

> 主题：LLMs（大语言模型）持续更新~ › 五：提示工程与上下文学习　｜　原始文件：LLMs（大语言模型）持续更新~/五：提示工程与上下文学习/82.大模型（LLMs）ReAct.md

## 题1：ReAct（Reasoning + Acting）框架的核心思想是什么？它如何结合推理与行动？

ReAct 框架的核心思想是让大语言模型在解决复杂任务时，不再仅仅依赖内部参数化知识进行孤立推理，而是将推理（Reasoning） 与行动（Acting） 紧密交织在一起。模型被允许在生成最终答案的过程中，随时向外部世界发起操作（如搜索、查询数据库、调用计算器），并将从外部环境返回的观察结果（Observation）直接作为新的上下文，指导后续的推理和行动。

这种结合方式模仿了人类解决复杂问题时的典型行为：我们不会凭空冥想，而是会“思考一步，然后查一下资料，根据查到的信息再思考，再行动，如此循环”。ReAct 将 LLM 视为一个智能代理，它拥有一个与外部环境交互的接口。每一轮中，模型首先产出一个思考（Thought），分析当前状态、明确需要什么信息或下一步计划；接着产出一个行动（Action），精确指定要调用的工具及其参数；然后系统执行该行动，将返回的观察（Observation）注入对话上下文；模型基于观察再次进入思考，如此反复，直到得出最终答案。

这种“推理-行动-观察”循环的优势在于：

- 实时获取最新、最准确的信息，弥补 LLM 内部知识的截止日期限制和领域覆盖不足。
- 通过外部工具辅助精确计算和操作，克服 LLM 在算术、逻辑执行上的弱点。
- 通过观察反馈自我纠错，当行动返回无效信息或模型发现推理矛盾时，可以调整策略，重新行动，提升鲁棒性。
- 提供可解释的推理-行动轨迹，用户可以清晰地看到模型每一步的思考过程以及从何获取的信息，增强可信度。

因此，ReAct 不是简单的“LLM+工具调用”，而是一种将工具使用有机融入复杂推理过程的动态交互框架，为构建真正能够“思考并行动”的智能 Agent 奠定了基础。

## 题2：描述 ReAct 的典型循环：思考 → 行动 → 观察 → 思考...

ReAct 的典型工作循环是一个迭代的、交替的序列，直到模型认为已经掌握了足够信息来回答用户问题。这个循环可以分解为以下阶段：

1. 思考（Thought）：模型分析当前状态，包括原始问题和已经积累的观察历史。它思考当前还缺少什么信息，下一步应该做什么来推进解决。思考是内在推理，不直接改变外部环境。例如：“我需要找出2023年诺贝尔物理学奖得主的出生地。首先我得知道他/她是谁，我需要搜索获奖者名字。”
1. 行动（Action）：基于思考，模型决定采取一个具体的行动，并给出行动的参数。行动是显式的、可被解析的指令，用于调用外部工具。例如：Search[2023年诺贝尔物理学奖得主]。行动空间通常是预定义的，如搜索、查找数据库、调用计算器等。
1. 观察（Observation）：这是从外部环境返回的结果。系统执行模型指定的行动，并将结果以文本形式返回给模型。例如，搜索引擎返回一段摘要：“2023年诺贝尔物理学奖授予皮埃尔·阿戈斯蒂尼、费伦茨·克劳斯和安妮·吕利耶...” 观察被直接注入到对话上下文中，作为下一步推理的事实基础。
1. （循环）再次思考：模型阅读观察结果，更新自己的理解。它可能从观察中提取出所需的关键信息（如得奖者姓名），然后继续思考下一步：现在有了名字，还需要他们的出生地。于是生成新的思考，接着再次发起行动（如搜索“皮埃尔·阿戈斯蒂尼 出生地”）。这个循环持续进行，模型可能进行多轮搜索，逐步逼近最终答案。
1. 终止与最终答案（Final Answer）：当模型认为已经收集到足够的信息，或者任务已经完成时，它会生成一个特殊的“最终答案”行动，或直接输出最终回答。例如：Final Answer: 皮埃尔·阿戈斯蒂尼出生于法国...。

这种交替循环使 LLM 能够动态地根据外部信息调整推理方向，而不是一早就定下整个计划。它具有极强的适应性和鲁棒性，因为每一步行动都是基于最新的全部历史做出的。

## 题3：在 ReAct 中，推理步骤（Thought）和行动步骤（Action）如何交替进行？请画出流程图。

在 ReAct 中，推理和行动严格交替，形成“思考→行动→观察→思考→行动→观察”的链条。模型生成的内容只包含 Thought 和 Action，而 Observation 由外部环境注入。具体交替流程如下：

[用户问题]
 │
 ↓
┌──────────────────────────────────────┐
│  LLM 生成                             │

│  Action: Search[查询词]                │
└──────────────┬───────────────────────┘
               │  调用搜索工具
               ↓

│  外部环境返回                          │

               ↓
┌──────────────────────────────────────┐
│  LLM 继续生成                          │
