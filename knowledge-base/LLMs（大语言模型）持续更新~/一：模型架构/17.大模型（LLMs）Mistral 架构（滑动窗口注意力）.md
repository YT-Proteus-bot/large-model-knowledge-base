## 题1：Mistral 7B 的滑动窗口注意力是如何工作的？窗口大小是多少？

Mistral 7B 使用滑动窗口注意力（Sliding Window Attention, SWA），窗口大小 W = 4096 token。

工作原理：

- 在每一层，对于位置为 i*i* 的 token，其注意力只能看到范围在 [*i*−*W*+1,*i*] 内的过去 token（及自身），而不能关注更早的 token。
- 这相当于在标准因果掩码的基础上，进一步屏蔽距离超过窗口大小的历史 token。

## 题2：画出滑动窗口注意力的掩码模式，并与标准因果掩码对比。

标准因果掩码（n=8*n*=8 示例）：

```
      K0 K1 K2 K3 K4 K5 K6 K7
Q0 [  1, 0, 0, 0, 0, 0, 0, 0]
Q1 [  1, 1, 0, 0, 0, 0, 0, 0]
Q2 [  1, 1, 1, 0, 0, 0, 0, 0]
Q3 [  1, 1, 1, 1, 0, 0, 0, 0]
Q4 [  1, 1, 1, 1, 1, 0, 0, 0]
Q5 [  1, 1, 1, 1, 1, 1, 0, 0]
Q6 [  1, 1, 1, 1, 1, 1, 1, 0]
Q7 [  1, 1, 1, 1, 1, 1, 1, 1]
```

（1 表示可见，0 表示被掩码屏蔽）

滑动窗口因果掩码（W=3*W*=3 示例）：

```
      K0 K1 K2 K3 K4 K5 K6 K7
Q0 [  1, 0, 0, 0, 0, 0, 0, 0]
Q1 [  1, 1, 0, 0, 0, 0, 0, 0]
Q2 [  1, 1, 1, 0, 0, 0, 0, 0]
Q3 [  0, 1, 1, 1, 0, 0, 0, 0]
Q4 [  0, 0, 1, 1, 1, 0, 0, 0]
Q5 [  0, 0, 0, 1, 1, 1, 0, 0]
Q6 [  0, 0, 0, 0, 1, 1, 1, 0]
Q7 [  0, 0, 0, 0, 0, 1, 1, 1]
```

每个 query 只能看到最近的 W*W* 个 key（包含自身）。

核心区别：滑动窗口掩码将注意力限制在固定宽度的带状区域内，而标准因果掩码让每个 token 看到所有历史。

## 题4：在滑动窗口中，远处的信息如何传递？是否会有信息丢失？
