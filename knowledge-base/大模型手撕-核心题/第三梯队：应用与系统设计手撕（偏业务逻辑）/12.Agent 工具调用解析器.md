# 12.Agent 工具调用解析器

> 主题：大模型手撕-核心题 › 第三梯队：应用与系统设计手撕（偏业务逻辑）　｜　原始文件：大模型手撕-核心题/第三梯队：应用与系统设计手撕（偏业务逻辑）/12.Agent 工具调用解析器.md

## 题1：实现一个函数，解析 LLM 输出的文本，提取其中的 JSON 函数调用：输入包含 json {...} 代码块的字符串，返回解析后的 JSON 对象（字典），若解析失败则抛出异常。

原理

LLM 经常以 Markdown 代码块的形式输出 JSON，例如：

Here is the function call:

```
{"name": "search", "arguments": {"query": "weather"}}
```

```
我们需要提取代码块内的 JSON 字符串，并解析为 Python 字典。实现时需考虑以下情况：
- 标准 ````json ... ``` ` 代码块。
- 代码块中可能包含转义字符、多余空白。
- LLM 可能直接输出 JSON 对象而不包含代码块标记。
- JSON 解析可能失败（格式错误），此时应抛出异常并包含明确的错误信息。
**实现**
```python

import json

import re

from typing import Dict, Any

def extract_json_from_text(text: str) -> Dict[str, Any]:

    """

    从 LLM 输出的文本中提取 JSON 函数调用。

    支持 ```json``` 代码块或直接 JSON 对象。

    Args:

        text: LLM 原始输出字符串

    Returns:

        dict: 解析后的 JSON 对象

    Raises:

        ValueError: 未找到 JSON 或解析失败

    """

## 题2：尝试提取 ```json ... ``` 代码块

## 使用非贪婪匹配，支持多行

    pattern = r'```json\s*([\s\S]*?)\s*```'

    match = re.search(pattern, text)

    if match:

        json_str = match.group(1).strip()

        try:

            return json.loads(json_str)

        except json.JSONDecodeError as e:

            raise ValueError(f"JSON 解析失败: {e}\n内容: {json_str}")

## 题3：如果没有代码块，尝试寻找第一个 '{' 和最后一个 '}' 之间的内容

## 这是一个简单启发式，适用于 LLM 直接输出 JSON 对象的情况

    start = text.find('{')

    end = text.rfind('}')

    if start != -1 and end != -1 and end > start:

        json_str = text[start:end+1]

        try:

            return json.loads(json_str)

        except json.JSONDecodeError as e:

            raise ValueError(f"JSON 解析失败: {e}\n内容: {json_str}")

## 题4：都没找到，抛出异常

    raise ValueError("未找到有效的 JSON 对象")

## 示例测试

if __name__ == "__main__":

## 测试1: 代码块

    text1 = '好的，调用如下：\n```json\n{"name": "get_weather", "arguments": {"city": "北京"}}\n```'

    print(extract_json_from_text(text1))

## 测试2: 直接 JSON

    text2 = '{"name": "search", "arguments": {"query": "AI"}}'

    print(extract_json_from_text(text2))

## 测试3: 无效 JSON 应抛出异常

    try:

        extract_json_from_text("这不是 JSON {name: test}")

    except ValueError as e:

        print("捕获异常:", e)
