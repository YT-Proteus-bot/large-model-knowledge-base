## 机器学习笔试/面试题 七

本文讨论了机器学习笔试/面试题，涵盖变量相关性、回归模型、残差分析等多个知识点的题目及答案解析。关键要点包括：

变量相关性：两个相关变量不一定有线性关系，相关系数可以为零。

回归模型特征值：在逻辑回归模型中加入新特征值，训练精度总是上升或不变，若特征显著，测试精度会上升。

Ridge回归：lambda很大时，偏差大、方差小；lambda很小时，偏差小、方差大；lambda为0时类似线性回归，趋向无穷时相关系数趋近0。

残差分析：预期值和残差应无关系，残差图显示有明显关系的模型较差；移除离回归拟合线远的异常值对拟合线影响大。

回归方法解的情况：Lasso回归相关系数无闭式解，因L1 - penalty使解为非线性。

回归模型输出变化：简单线性回归中，改变输入变量1单元，输出变量变化值为斜率值。

逻辑回归概率转换：使用Sigmoid函数将逻辑回归输出结果转换到[0, 1]区间。

## 题17：7、在简单线性回归模型中（单自变量），如果改变输入变量1单元，输出变量会变化多少？

## 题28：5、假设线性回归模型完美拟合训练数据（即训练误差为零），则下列哪项是正确的？

A 测试误差一定为零

B 测试误差一定不为零

C 以上都不对

正确答案是：C

解析： 如果测试数据无干扰，则测试误差可能为零。换言之，如果测试数据是训练数据的典型代表，测试误差即为零，但这种情况并不总是出现。

## 题29：6、在线性回归问题中，我们用R方“R-squared”来衡量拟合的好坏。在线性回归模型中增加特征值并再训练同一模型。下列哪一项是正确的？

A 如果R方上升，则该变量是显著的

B 如果R方下降，则该变量不显著

C 单单R方不能反映变量重要性，不能就此得出正确结论

D 都不正确

正确答案是：C

解析： 单单R方不能表示变量显著性，因为每次加入一个特征值，R方都会上升或维持不变。但在“调整R方”的情况下这也有误（如果特征值显著的话，调整R方会上升）。

## 题30：7、下列关于回归分析中的残差表述正确的是：

A 残差的平均值总为零

B 残差的平均值总小于零

C 残差的平均值总大于零

D 残差没有此类规律

正确答案是：C

解析： 残差总是为正的，BD不正确.因此回归的残差之和一般情况总是大于为零，故而平均值也大于零。因为模型很少情况下做到完全拟合，A不正确。

## 题31：8、下列哪一项说明了X，Y之间的较强关系？

B Beta系数为0的空假设的p-value是0.0001

解析： 变量间的相关系数为0说明了变量间的较强关系；另一方面，p-value和t统计量仅仅衡量了非零联系的证据有多强。在数据足够多的情况下，哪怕弱影响都可能是显著的。
