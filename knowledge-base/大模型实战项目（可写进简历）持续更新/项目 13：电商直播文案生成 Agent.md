## 题1：项目概述

"带货 —— 电商直播文案生成 Agent"是一个基于大语言模型的电商直播内容生产系统。系统接收商品结构化数据（JSON），自动完成卖点提取、多阶段直播话术生成（开场/产品介绍/促单/逼单）、观众互动回复，并支持激情、专业、幽默三种风格切换。核心技术栈为 Python + LangChain + FastAPI，推理模型采用 Qwen-7B-Chat，通过 vLLM 在单张 24G 显存 GPU 上部署，支持 SSE 流式输出。

> 🎯 **项目目标**：将直播文案的生产效率从"人工撰写 30 分钟/品"提升到"AI 生成 30 秒/品"，同时保证话术的卖点准确性、风格一致性和转化引导力。

## 题4：1 系统架构总览

系统采用五层架构：客户端层 → API 网关层 → 业务编排层 → 模型服务层 → 数据存储层。各层之间通过明确的接口契约解耦，便于独立扩展和替换。

## 题5：2 各模块职责详解

### 2.2.1 API 网关层（FastAPI）

- **请求路由**：提供 RESTful 接口，区分话术生成、卖点提取、互动回复三类端点
- **参数校验**：使用 Pydantic 模型校验输入，拒绝非法商品 JSON 和越界参数
- **流式输出**：通过 StreamingResponse + SSE（Server-Sent Events）实现逐字推送
- **限流与鉴权**：基于 API Key 的简单鉴权，单 IP 每分钟 60 次限流
- **异常处理**：统一异常中间件，模型超时返回 504，参数错误返回 422 并附带字段定位

### 2.2.2 业务编排层（LangChain）

- **商品理解模块**：解析商品 JSON，标准化字段（名称、价格、规格、成分、产地、用户评价等），补全缺失字段的默认值
- **卖点提取 Chain**：LLMChain + 结构化输出解析器，从商品数据中提取 3-5 个核心卖点，输出 Pydantic 模型
- **话术生成 Chain**：核心 Chain，接收卖点 + 风格 + 话术类型，通过 RunnableSequence 串联 Prompt 模板 → 模型 → 输出解析
- **风格控制器**：维护三种风格的 Prompt 前缀和参数预设（temperature、top_p、frequency_penalty），运行时注入到生成 Chain
- **互动回复 Chain**：两步 Chain——先意图分类（8 类预设意图），再基于意图和商品上下文生成回复
- **上下文管理器**：维护直播间会话上下文（最近 10 轮互动 + 当前讲解商品），控制 token 窗口在 4K 以内

### 2.2.3 模型服务层

- **Qwen-7B-Chat**：主推理模型，7B 参数，中文能力强，支持 8K 上下文，24G 显存可以 FP16 精度运行（约 14GB 显存），剩余显存供 KV Cache 和并发
- **vLLM 推理引擎**：PagedAttention 技术，显存利用率提升 2-4 倍，支持连续批处理（continuous batching），单卡并发可达 8-16 请求
- **Prompt 模板库**：Jinja2 模板，按功能模块和风格分类管理，支持版本号追踪
