## 一、项目概述

> 🎯 **视界（VisionScope）**是一个面向图文混排文档的多模态 RAG 系统。它能解析 PDF/扫描件/图片中的文字、表格、图表和版面结构，通过多模态嵌入实现跨模态检索，并结合 Qwen2-VL 大模型完成精准问答。

**核心能力：**

- 图文混排文档解析：保留版面结构，分离文字、表格、图片、公式
- 扫描件 OCR：PaddleOCR PP-OCRv4 中英文识别，支持倾斜校正和版面分析
- 表格识别与问答：表格结构还原 + 自然语言 SQL/直接问答
- 多模态检索：Chinese-CLIP 图文联合嵌入，支持"以文搜图"和"以图搜文"
- 多模态生成：Qwen2-VL-7B 理解检索到的图片+文本上下文，生成答案

## 题2：2 各模块职责详解

### 模块 A：文档解析引擎（Document Parser）

- **输入：**PDF / 图片 / Word / 扫描件
- **处理流程：**PyMuPDF 提取原生文本和图片 → 对无文本层的页面调用 PaddleOCR → PaddleStructure 做版面分析（区分标题/正文/表格/图片/公式区域）→ 按阅读顺序重组
- **输出：**结构化 Document 对象，包含 text_chunks、table_chunks、image_chunks、layout_bbox
- **关键设计：**每个 chunk 携带 page_num、bbox、chunk_type、source_file 元数据，用于后续引用溯源

### 模块 B：多模态嵌入与索引（Embedding & Indexing）

- **文本嵌入：**BGE-large-zh（1024维）处理纯文本 chunk
- **图像嵌入：**Chinese-CLIP ViT-L/14（768维）处理图片 chunk 和表格截图
- **统一空间：**Chinese-CLIP 的 text encoder 同时对文本 chunk 编码，使文本和图片落在同一向量空间，实现跨模态检索
- **双索引设计：**Milvus 集合1存文本向量（BGE），集合2存多模态向量（CLIP）；查询时并行检索后融合

### 模块 C：表格问答引擎（Table QA）

- **表格还原：**TableTransformer 检测表格边界 + 识别行列结构 → 输出 HTML/Markdown 表格
- **问答策略（双路径）：**
- 路径1（简单查询）：表格转 Markdown → 直接拼入 LLM 上下文 → Qwen2-VL 生成答案
- 路径2（复杂计算）：LlamaIndex TableQueryEngine → Text-to-SQL（SQLite 内存库）→ 执行 SQL → 结果返回 LLM 组织语言
- **表格截图兜底：**对结构复杂的表格，同时保存截图，由 Qwen2-VL 直接视觉理解

### 模块 D：RAG 检索生成（Retrieval & Generation）

- **查询理解：**Qwen2-VL 判断查询类型（文本事实/图表理解/表格数据/跨模态），决定检索路径
- **混合检索：**BM25（关键词）+ BGE 向量（语义）+ CLIP 跨模态（图文）三路召回，各取 Top-10
- **重排：**BGE-Reranker-v2-m3 对融合结果重排取 Top-5
- **上下文组装：**文本 chunk 直接拼接；图片 chunk 以 base64 嵌入 Qwen2-VL 输入；表格 chunk 附 Markdown + 截图
- **生成与校验：**Qwen2-VL 生成答案 → 引用校验（答案中的事实必须能在检索上下文中找到）→ 输出答案+引用页码/图片
