# 项目 8：浏览器自动化 Agent

> 主题：大模型实战项目（可写进简历）持续更新　｜　原始文件：大模型实战项目（可写进简历）持续更新/项目 8：浏览器自动化 Agent.md

## 一、项目概述

**触手（Tentacle）** 是一个基于大语言模型的浏览器自动化 Agent，能够接收自然语言任务指令，自主完成网页导航、信息抓取、表单填写和多步骤网页操作。项目核心思路是将 LLM 的语义理解能力与 Playwright 的精确浏览器控制能力结合，通过 LangGraph 构建可观测、可回溯的状态机执行循环。

> 🎯 **核心能力**：网页导航（点击/输入/滚动/等待）、结构化信息抓取（列表/表格/详情页）、表单自动填写（含下拉/复选/日期选择器）、多步骤任务编排（登录→搜索→筛选→导出）。

│                 认知层 (LLM Core)                     │
│   ┌──────────┐  ┌──────────────┐  ┌──────────────┐  │
│   │  Planner │  │ PageParser   │  │  Reflexion   │  │

│   └────┬─────┘  └──────┬───────┘  └──────┬───────┘  │
│        └────────────────┼─────────────────┘          │
│                         ▼                            │
