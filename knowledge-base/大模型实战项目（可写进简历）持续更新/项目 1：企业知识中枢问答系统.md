## 一、项目概述

> 🎁 "知源"是一套面向企业内部的知识中枢问答系统，核心目标是让员工能够用自然语言提问，从企业内部多格式文档（PDF、Word、Markdown、HTML、Excel 等）中精准获取答案，并附带可追溯的引用来源。

系统采用 **检索增强生成（RAG）** 架构，通过"文档解析 → 分块 → 向量化 → 混合检索 → 重排序 → LLM 生成 → 引用标注"的完整流水线，在保证回答准确性的同时，提供来源可追溯、多轮对话可记忆的交互体验。

> 🎯 **核心指标目标：**检索 Top-5 召回率 ≥ 90%，重排序后 Top-3 准确率 ≥ 85%，回答引用命中率 ≥ 95%，首字延迟 < 2s，端到端延迟 < 8s。

### 数据流 A：文档入库（离线/异步）

1. 用户通过 /upload 上传文档 → 文件存入 MinIO，记录元数据到 PostgreSQL（status=pending）
1. 后台 Worker 消费任务 → 调用文档解析器提取纯文本 + 结构化元素
1. 智能分块 → 生成带元数据的 Document 列表（chunk_size=512, overlap=64）
1. 批量向量化（BGE-large-zh, batch=32）→ 得到 [chunk_id, vector(1024d), metadata]
1. 并行写入：向量 → Milvus 集合；文本 → BM25 索引（Whoosh/ES）；元数据 → PostgreSQL
1. 更新文档状态为 ready，记录 chunk 总数和向量化耗时

### 数据流 B：问答查询（在线/同步）

1. 用户发送问题 + session_id → FastAPI 接收，生成 request_id
1. 查询改写：若存在对话历史，用 LLM 将当前问题改写为独立查询（query rewriting）
