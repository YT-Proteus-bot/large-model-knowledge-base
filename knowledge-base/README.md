## 使用说明

- 导入 RAG 平台时排除 `_meta/` 与各目录下的 `_index.md`（索引文件，非正文）。
- 建议切片：按 `## ` 标题切分，chunk 400～800 字，overlap 50～100 字；入库时把文件名 + `# 标题` + `## 题N` 一起拼进 chunk，可显著改善召回。
- 原文图片已失效（源 assets 目录缺失），正文统一以 `> 〔图片：…〕` 占位，按需补图后再更新对应文件。
- 字段与清洗规则见 `_meta/处理说明.md`，逐篇清册见 `_meta/catalog.csv`。
