## 对 Markdown 做的加工

| 项 | 处理方式 |
| --- | --- |
| 飞书提示语 | 删除「手机浏览器打开」「阅读约定」等导出残留文案 |
| `> 原文：` 链接 | 移入 front matter 的 `source_url`，正文不再保留 |
| 失效图片 | 原文 assets 目录已缺失，图片统一替换为 `> 〔图片：…〕` 占位（共替换 726 处） |
| 内嵌组件 | 「需登录飞书查看」的文档部件/电子表格替换为占位说明 |
| 复选框 | `- [ ]` 转为普通列表项 |
| 代码块 | 删除飞书导出的「代码块」占位行，保留代码与缩进 |
| 分隔线 | 删除 `---` 等无信息分隔线 |
| 标题层级 | 只保留 `#`（文档标题）、`## 题N：…`（题目）、`##`/`###`（小节）；超出层级的标题夹逼到 2～3 级 |
| 题号 | 同一文档内题号重复、缺失或不是从 1 连续编号时，按出现顺序统编为 题1…题N |
| 正文文字 | 不改写、不扩写、不缩写 |

## 对 PDF 做的加工

- 按字号识别标题（正文主字号 ×1.10 以上视为标题，×1.6 以上视为一级小节），按行距合并断行，保留段落与列表。
- 删除跨页重复的页眉页脚、纯页码行。
- 图片型 PDF 先尝试 OCR（RapidOCR，2 倍渲染），OCR 结果过短或失败则列入 `pdf_failures.csv`。
- 表格会被展开为纯文本行，网格线丢失，检索可用、阅读体验一般。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| `title` | 文档标题（原文 H1，缺失时用文件名） |
| `topic` / `sub_topic` | 一级 / 二级主题目录 |
| `doc_type` | `md`（原文即 Markdown）/ `pdf`（PDF 转写）/ `index`（索引文件） |
| `source_url` | 原文飞书链接（仅 Markdown 有） |
| `source_path` | 在源项目中的相对路径，便于回溯 |
| `questions` | 本文识别出的题目数 |
| `chars` | 正文字符数（不含 front matter） |
| `images_removed` | 被替换为占位的图片处数 |
| `pages` | PDF 页数 |
| `build_date` | 构建日期 |

## 已知局限

- 公式以图片形式存在时，转写后只剩占位符；PDF 内的公式多为图片，同样无法还原。
- OCR 结果为机器识别，个别字词可能有误，重要结论建议核对原始 PDF。
- 少数纯散文式文档（标题即主题而非问句）没有 `## 题N` 结构，按小节切分即可。
