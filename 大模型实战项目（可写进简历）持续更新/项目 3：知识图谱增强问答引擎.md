# 项目 3：知识图谱增强问答引擎

> 原文：https://lcnipys9u0xh.feishu.cn/wiki/RiSowOrKgioyl9kuXm4ccyNxnSe

## 1. 项目概述

"织网"是一个面向非结构化文档的知识图谱增强问答引擎。核心思路是：从文档中自动抽取实体与关系构建知识图谱，在问答时同时利用图遍历（结构化多跳推理）和向量检索（语义模糊匹配），将两种证据融合后交给大模型生成答案。相比纯向量 RAG，它在需要跨文档、跨实体链式推理的问题上准确率显著更高。

> 🎯 **核心能力**：实体关系自动抽取 → 知识图谱构建 → 图遍历与向量检索双路召回 → 融合重排序 → 多跳推理问答。

## 2. 系统架构设计

### 2.1 整体架构

系统分为**离线构建层**和**在线问答层**两大部分。离线层负责从原始文档到知识图谱和向量库的全量构建；在线层负责接收用户问题、双路检索、融合生成。

### 2.2 模块职责

模块

职责

关键技术

文档预处理

读取 PDF/Markdown/HTML，按语义段落切分，清洗噪声，保留元数据（来源、页码、章节）

LangChain Document Loaders、RecursiveCharacterTextSplitter

实体关系抽取

对每个文本块调用 Qwen-7B-Chat，按预设 Schema 输出实体列表和关系三元组，输出为结构化 JSON

Qwen-7B-Chat、Function Calling / JSON Mode、Prompt 模板

实体对齐与消歧

对抽取结果做实体归一化（别名合并、指代消解），计算实体相似度去重，生成全局唯一实体 ID

字符串相似度（rapidfuzz）、向量相似度、规则映射表

图谱构建

将实体作为节点、关系作为边写入 Neo4j，设置标签、属性、索引；记录每条边的来源文本块 ID

Neo4j Python Driver、Cypher、约束与索引

向量库构建

对文本块生成嵌入向量，写入 Chroma，同时存储原文、来源、元数据

BGE-large-zh、Chroma、LangChain VectorStore

Query 理解

对用户问题做意图识别、子问题分解、查询改写；提取问题中的实体并链接到图谱节点

Qwen-7B-Chat、实体链接（模糊匹配 + 向量召回）

图遍历检索

从链接到的实体出发，执行 1~3 跳 Cypher 查询，获取邻居子图、路径和关联文本；支持关系类型过滤

Neo4j Cypher、路径查询、APOC 过程（可选）

向量检索

用改写后的 Query 向量在 Chroma 中做 Top-K 相似度检索，返回相关文本块

Chroma similarity_search、MMR 去重

融合与重排序

对图检索结果和向量检索结果去重、交叉打分，按相关性重排序，截取 Top-N 作为上下文

RRF 融合算法、交叉编码器重排（可选）、规则打分

答案生成

将融合后的上下文（图路径 + 文本块）和用户问题组装成 Prompt，调用 Qwen-7B-Chat 生成答案，附引用来源

Qwen-7B-Chat、LangChain RunnableSequence、引用标注

### 2.3 数据流

**离线数据流**：原始文档 → 切分清洗 → 文本块（带元数据）→ 并行两路：① 实体关系抽取 → 对齐消歧 → Neo4j 写入；② 文本嵌入 → Chroma 写入。两路通过文本块 ID 关联，图谱中的每条边都记录 source_chunk_id 指向原始文本块。
