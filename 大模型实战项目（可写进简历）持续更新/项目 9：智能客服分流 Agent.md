# 项目 9：智能客服分流 Agent

> 原文：https://lcnipys9u0xh.feishu.cn/wiki/ThTTwDbqiiue7akDR2jcyZc7nWg

## 一、项目概述

"百晓"是一个基于大语言模型的智能客服分流系统，定位为**意图识别与路由 + 知识库检索 + 工单查询工具 + 低置信度转人工 + 多轮对话管理**的一体化客服 Agent。系统能够自动判断用户问题类型，选择最优处理路径（知识库回答 / 工单操作 / 转人工），并在多轮对话中维持上下文状态。

> 🎯 **核心目标**：将 70% 以上的常见客服问题自动化解决，剩余复杂问题高效转接人工，同时保证回复准确性和用户体验。
