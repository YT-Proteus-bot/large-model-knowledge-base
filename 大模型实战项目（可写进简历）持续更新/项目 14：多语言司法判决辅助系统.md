## 一、项目概述

言枢（LexPivot）是一套基于大语言模型与法律 RAG 的司法判决辅助系统，面向法官、检察官与执业律师，提供四大核心能力：**类案检索**、**判决结果预测**、**法律文书自动生成**、**量刑建议**。系统支持中文与英文双语输入，通过向量相似度检索 + 多维度结构化过滤实现精准类案匹配，以 Qwen-7B-Chat 为基座模型结合法律领域 RAG 完成预测与生成任务。

> 💡 **定位声明**：本系统为"辅助决策"工具，所有预测、建议与生成内容均需法律专业人员审核确认，不替代法官独立裁判，不构成法律意见。

### 2.2 端到端数据流

以"输入一起盗窃案件事实，获取类案 + 预测 + 量刑建议 + 生成判决书"为例：

1. **请求接入**：客户端 POST /api/v1/analyze，传入案件事实文本（中/英）、案由、被告人信息等字段。
1. **预处理**：多语言检测 → 非中文自动翻译为中文（Qwen 翻译）→ 案件要素 NER 抽取（被告人、被害人、金额、时间、地点、手段）→ 构建结构化案件对象。
1. **检索层召回**：案件事实文本经 BGE Embedding 向量化 → Milvus 向量检索 Top-50 → 多维度过滤（案由=盗窃、法院层级、年份范围、量刑区间）→ BM25 关键词补充召回 → BGE-Reranker 重排序 → Top-10 类案。
1. **法条检索**：从类案中提取引用法条 → 法条知识库精确匹配 → 获取法条原文与司法解释。
1. **预测层推理**：将案件事实 + Top-5 类案摘要 + 相关法条组装为 Prompt → Qwen-7B-Chat 生成预测（罪名、刑期区间、罚金、缓刑可能性）→ 输出解析器提取结构化结果 → 置信度计算（基于类案判决一致性 + 模型 logprob）。
1. **量刑建议**：基于预测层结果 + 量刑指导意见规则引擎（基准刑 → 调节情节 → 宣告刑）→ 生成量刑建议书。
1. **生成层出文**：选择文书模板（一审刑事判决书）→ 模板槽位填充（当事人信息、事实认定、判决理由、判决主文）→ LLM 生成"本院认为"说理部分 → 法条引用校验 → 格式校验 → 输出 DOCX。
1. **结果返回**：聚合类案列表、预测结果、量刑建议、文书下载链接 → JSON 响应。

### 2.3 多语言处理架构

系统采用"中文为中枢"的多语言策略：所有非中文输入先翻译为中文，在中文法律知识空间内完成检索与推理，输出时按需翻译回目标语言。这样做的原因是中文裁判文书库与法律知识体系最为完备，Qwen-7B-Chat 的中文法律推理能力优于英文直接推理。

- 输入侧：fasttext 语言检测 → Qwen-7B-Chat 翻译（法律术语对照表约束）→ 中文案件对象
- 检索侧：统一中文向量空间，英文案件通过翻译后入库
- 输出侧：中文结果 → 按需翻译为英文（保留法条编号与专有名词原文）
