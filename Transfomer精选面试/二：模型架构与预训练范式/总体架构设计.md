# 总体架构设计

> 原文：https://lcnipys9u0xh.feishu.cn/wiki/PHhXw9KAQi5j4Xk3ud7cYLghnkh

#### 1. 画出标准 Transformer 的 Encoder 和 Decoder 结构图，标注所有子层

Encoder（编码器）：

```
代码块
输入嵌入 + 位置编码
       │
       ▼
   ┌─────────────────────────────┐
   │         Encoder Layer       │
   │                             │
   │  ┌──────────────────────┐   │
   │  │ 多头自注意力 (Multi-Head   │   │
   │  │ Self-Attention)        │   │
   │  └──────────────────────┘   │
   │           │                  │
   │    残差连接 + LayerNorm       │
   │           │                  │
   │  ┌──────────────────────┐   │
   │  │  前馈网络 (FFN)        │   │
   │  └──────────────────────┘   │
   │           │                  │
   │    残差连接 + LayerNorm       │
   │                             │
   └─────────────────────────────┘
       │
       ▼
   （× N，通常 6、12、24 层叠加）
       │
       ▼
  Encoder 输出（送给 Decoder 的交叉注意力）
```

Decoder（解码器）：

```
代码块
目标序列嵌入 + 位置编码
       │
       ▼
   ┌─────────────────────────────┐
   │         Decoder Layer       │
   │                             │
   │  ┌──────────────────────┐   │
   │  │ 掩码多头自注意力       │   │
   │  │ (Masked Multi-Head    │   │
   │  │  Self-Attention)      │   │
   │  └──────────────────────┘   │
   │           │                  │
   │    残差连接 + LayerNorm       │
   │           │                  │
   │  ┌──────────────────────┐   │
   │  │ 交叉注意力            │   │
   │  │ (Cross-Attention)     │   │
   │  │ Q: Decoder输出         │   │
   │  │ K,V: Encoder输出      │   │
   │  └──────────────────────┘   │
   │           │                  │
   │    残差连接 + LayerNorm       │
   │           │                  │
   │  ┌──────────────────────┐   │
   │  │  前馈网络 (FFN)        │   │
   │  └──────────────────────┘   │
   │           │                  │
   │    残差连接 + LayerNorm       │
   │                             │
   └─────────────────────────────┘
       │
       ▼
   （× N，通常与 Encoder 层数相同）
       │
       ▼
   Linear + Softmax → 输出概率
```
