# 如何理解面向对象和面向过程？

> 原文：https://lcnipys9u0xh.feishu.cn/wiki/Ac4Ow9Y6Oi8AvlkKC0IcyIbYnIg

#### 面试回答模板

面试官： 你怎么理解面向对象和面向过程？

你：

我用洗衣服的例子说。面向过程是“按步骤做”，面向对象是“让对象去做”。

面向过程： 思路就是洗衣服四步走——放衣服、加洗衣液、洗、烘。写代码就是定义四个函数，一个接一个调用。简单直接，但如果要洗不同材质的衣服，就得在函数里加一堆 if-else，代码越改越乱。

面向对象： 不关注步骤，关注有哪些“东西”以及它们能做什么。洗衣机对象负责洗，烘干机对象负责烘。洗羊毛衫？给洗衣机设个轻柔模式就行。数据和行为绑在一起，改洗衣机内部不影响外面。

区别一句话：面向过程围绕“怎么做”，面向对象围绕“谁来做”。

什么时候用？ 业务稳定流程固定的脚本、算法用面向过程。系统复杂、功能老变的业务系统用面向对象。
