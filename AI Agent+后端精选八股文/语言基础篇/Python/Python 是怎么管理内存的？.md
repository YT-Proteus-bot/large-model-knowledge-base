### 1️⃣ 心理模型：变量是"便利贴"，不是"盒子"

很多新手把变量理解成"装值的盒子"，这是第一个要纠正的观念。**Python 里没有"盒子"，只有"对象"和"名字"。**

#### 1.1 一切皆对象：id / type / value 三件套

在 Python 中，任何数据（数字、字符串、函数、类……）都是一个对象。每个对象都有三样东西：

属性

含义（人话版）

怎么查

id

对象在内存中的"门牌号"，独一无二，决定了"是不是同一个对象"

id(obj)

type

对象的"物种"，决定它有哪些行为

type(obj)

value

对象携带的"数据本身"，如数字 42、字符串 "hi"

直接读取变量

#### 1.2 赋值 = 贴一张便利贴

```
为什么 b 改了，a 也变了？
a = [1, 2, 3]   # 在内存中创建列表对象，并把名字 a 贴上去
b = a           # 不是复制！只是又贴了一张叫 b 的便利贴
b.append(4)     # 修改的是同一个列表对象
print(a)        # [1, 2, 3, 4]  ← a 也"变"了
print(a is b)   # True         ← 两个名字指着同一个对象
```

> 💡 **生活类比：**对象是一间"屋子"，变量名是贴在门上的"便签"。贴两张便签（a、b）指向同一间屋子，你在屋里放一张床（append），从哪张便签进来都能看到床。**赋值从不复制屋子，只复制便签。**

> 💡 **易错点：**真正想复制一份独立数据时，要用 copy.copy（浅拷贝）或 copy.deepcopy（深拷贝），或对列表用 a[:]、list(a)。否则"复制"出来的两个名字改一个、另一个也跟着变。

### 2️⃣ 内存的两大战区：栈（Stack）与堆（Heap）

Python 的内存并不是一块大平地，而是分工明确的两个区域。

对比项

栈 Stack

堆 Heap

存放什么

函数调用的"记账本"：局部变量名、函数调用的返回地址

真正的对象实体：列表、字典、实例……

分配/释放

函数一调用就压栈、一返回就弹栈，**自动且极快**

由引用计数 + GC 决定何时释放，**相对慢**

大小限制

有限（递归太深会 RecursionError）

受系统内存限制，理论上大得多

类比

酒店前台：谁先来谁先办，办完就走（后进先出）

后台仓库：住客对象长期居住，由管理员（GC）定时清点

> 💡 **一句话记忆：**变量名（便利贴）在栈上，对象（屋子）在堆上。Python 帮你把"便签"和"屋子"之间的对应关系维护得明明白白，你只管贴便签。
